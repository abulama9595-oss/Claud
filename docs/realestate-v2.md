# The real-estate tool v2 (`realestate-v2.html`, `re2-engine.js`, `re2-ui.js`, `tests/re2/`) — reference

Moved out of `CLAUDE.md` unchanged (the phase-by-phase account of the build: data model, engine per kind, properties, lenses and advisor, the page, the search). The header comment of `re2-engine.js` is the source of truth for the model; this file is the long-form reference. Read the section you need, not the whole file.

**The real-estate tool (v2)** — five project kinds, every property you own, three strategy lenses, a settle-or-keep advisor, a decision-first answer page; the landing page's real-estate card. Forked from the old files, which stay **frozen** as the "previous version" (deleted later; their scenarios import into this one). Own `?v=` tag (sha1 of engine.js + re2-engine.js + re2-ui.js) and storage keys `re2_scenarios` / `re2_current` / `re2_current_name`. **Data model (P1):** `inp.kind` ∈ `landVilla` · `readyVilla` · `land` · `landBuilding` · `readyBuilding` (`mode`/`acquire` are derived in `mergeRE` via `RE_KINDS`, no rental mode), `occupancy` liveLet/let + unit keys, land keys (`landSellYear`, `landSellCostPct`, `landZakat`, `whiteLandPct`, `whiteLandOtherArea`), `rentFreezeUntil` (default 2030-09), `readyLandShare`/`readyAge`, `propertyValueBasis` market/today, `samaBands` (SAMA's bands for a single borrower too), bank terms `landOnlyLtv`/`landTenure`/`landRateAdd`, `invLtv`/`invTenure`/`invRateAdd`, `dscrMin`; **`inp.properties[]`** `{id, name, value, ltv, canMortgage, rentNow, isHome, plan keep|sell, sellAt, letAfterMove, letYield, sellCostPct, existingLoanId}` replaces `ownedValue`/`ownHome*` (`reNormProps`; a loan `securedOn` a property is a mortgage); plans carry `mortgages: {[propertyId]: {when, month}}` instead of `eqWhen/eqMonth` (`rePlanMorts`). Synthetic defaults (`properties: []`, cash 2,000,000, `plRate` 6.5, `lmRate` 5.0). **`re2Import(oldInp)`** converts an old-tool scenario (also applied automatically by `mergeRE` when `re2IsOld`) so the new engine gives the old engine's numbers: old defaults filled in, `propertyValueBasis: "today"`, `samaBands: false`, `rentFreezeUntil: null`, `eqWhen` → `mortgages.p1`, rental → a let-entirely building (`legacyRental`). Golden: `computeRE({ asOf: "2026-10" })` → `landVilla`, `prj.total` 3087912, RENTING WINS, best −2836605 (the rent freeze is on by default and counts from `asOf`; with `rentFreezeUntil: null` the best is −2422044); `computeRE(re2Import({}))` → the old golden. Tests: `tests/re2/` = the forked suite + `parity.test.js` (old engine vs new on 100+ synthetic scenarios, incl. the tool's pick) + `model.test.js` (import/merge idempotent, parity × ownHomePlan × eqWhen, market/today sizing, SAMA bands) + `kinds.test.js` (every kind: schedule sums and value continuity; land finance, holding costs month by month, the sale with the payoff; `reLetting`, a live-in building = an explicit annex rent, let-entirely = an explicit fixed rent; RETT per kind; the rent freeze channel by channel; verdict words; what-ifs and optimizer counts per kind; `kindScenarios` in `helpers.js`). **Engine (P2):** `reProject` builds each kind (`prj.kind/construct/isLand/isBuilding/moveIn/units/letting/saleAt/holding/holdingAt`): the villa kinds are the old numbers; a building is costed and valued like the villa and its units are let (`reLetting(p, prj)` → `{units, letUnits, perUnit, grossAnnual, netAnnual}`, per unit or per m² a year on `builtArea × netLettablePct`, net of vacancy and the management fee + VAT; `liveLet` → the annex channel `partIn`, `let` → the whole-home channel `letIn` with no move-in — you keep paying your rent; rent received never joins bank income); land only = land + RETT + broker at `landMonth`, no construction, `occupy = landMonth + 1` ("paid for"; `onHandAtMoveIn`/`recoveryOk`/`moveInOk` keep their meaning there), value = the land path, no upkeep, no cash-out (24 optimizer mixes), land finance on `lm` (`landOnlyLtv`, `landTenure`, `lmRate + landRateAdd`, `capTimeline` the same), holding costs (`whiteLandPct` from the first January after the purchase while `landArea + whiteLandOtherArea ≥ 5,000` m², `landZakat` "trade" 2.5%/yr; out of `cash` and `ccash`, `months.holding`, `r.holdingCost`), the planned sale (`prj.saleAt` = `landSellYear × 12`: value × (1 − `landSellCostPct`) − the `lm` payoff with the fee into cash, value 0 after, `r.landSale`, a `reGaps` closer); RETT first-home relief for the villa kinds only; `readyLandShare`/`readyAge` split a ready asset into growing land and an ageing building; the rent freeze (`rentFreezeUntil`, from `asOf` — this month when missing) holds every rent channel, paid and received, flat until that month (`reMonthIndex`, `reCalMonth`); verdicts `BUYING LAND WINS / NOT BUYING LAND WINS`, OWNING/RENTING only with rent today and a move-in; `stressRE`/`breakEvenRE`/`tornadoRE` per kind, `readyBreakEvenRE` only for `landVilla`; `timingSweepRE`/`optimizeRE` move the purchase for land. **Properties (P3):** every property you own is in the simulation — a facility `eq:<id>` per plan step (`mortgages[id]`; label "Mortgage on {name}", `propId`/`propName`/`labelLc`/`step`; `r.eqs[]` in property order, `r.eq` = the first or a blank one; `months.eqPay`/`debtEq` sum them; `mortgages = [lm, ...eqs, co]` in the mortgage cap, early payoff, `reCarryOut`, `loanWorthRE` — one row per eq), sized on value × ltv (`propertyValueBasis`) less the balance of the loan `securedOn` it (a loan a property names by `existingLoanId` is typed mortgage with `securedOn` filled in `mergeRE`), 0 once sold, refused with a reason ("{name} cannot be mortgaged" / "{name} was sold in month m" / you own no property); `rentNow` on both sides into cash (`months.propRentIn`/`propRentBase`, `r.propRentTotal`, in `onHandAtMoveIn`, never bank income); sales `r.sales[] {id, name, isHome, t, value, costs, payoff, fee, oldPayoff, oldFee, oldNames, net, side}` (`r.ownSale` = the home's): `sellAt: "moveIn"` sells on the strategy side at `occupy` (`ownGone` deducts it), a month sells on BOTH sides (`months.renterSale`; the baseline repays the secured loan via `renterSettle`; nothing in `ownGone`), the home you live in never before move-in; `reGaps(months, facs, sales, landSale)` closers `sale:<id>`; three `household.warnings` (a loan named by two properties, a property worth less than its loan, a plan that mortgages a property after selling it); `re2-ui.js` names the property everywhere (`planTitle(o, build, r, joint, props)`, `reSalesOf`, `reWealthParts` part `propRent`). `tests/re2/properties.test.js` (10 tests) + identities on `FAMILY3`. **Lenses, borrowing power, the settle-or-keep advisor (P4):** `months.room` `{dbr, mort, plSlots, capInst}` (+ `roomB` with تضامن) and `months.leverage` `{personal, mortgage, borrowable, ltv, room, inst}` are recorded at month end from the bank-test functions (so a loan taken next month finds `capacity.totalRoom === room.dbr`; `leverage` = the two-loan personal maximum, the mortgage min(LTV headroom of your properties and of the finished home at `cashoutLtv`, what `min(room.dbr, room.mort)` carries at the eq terms), `borrowable` = mortgage first then personal loans on the room left — a per-month record, kept cheap: annuity factors once per run, the fields before the record's only spread); results `peakDebt`/`peakDebtT`/`peakNewDebt`, `peakInstT`/`peakInstPct`, `profitPaid` (= `newDebtInterest`), `availAtMoveIn`/`leverageAtMoveIn`/`availEnd`/`leverageEnd`; `reWealthAt(r, years)`; **`reLenses(results, {liabilityBy peakDebt|borrowed|peakInst|profit, years, atMonth moveIn|horizon, robust, inp})`** over the shared `reLensPick` → `{recommended, leastLiability, richest, mostCash, candidates, byPlan}` (candidates = plans of the best standing; within 2% the next measure decides; `robust` = one rerun at 0% appreciation, on request); `optimizeRE` summaries carry the lens figures and `start.lenses`; **`rePvPayments`** extracted from `takePersonal` (`refiOptions[].value` bit-identical, in the parity key); **`reSettleAdvice(inp)`** → `household.settleAdvice`, one row per old loan (`verdict` keep · buyout · settleCash · room, `why`, PVs at the net cash return from k = 1, `stretch` = instalment relief, `rule7`, `roomValue`, `flatEquiv`); `settlePolicy: "dearer"` (`RE_BASE.dearerMargin` 0.25 — forMax on loans dearer than the mortgage; not in the optimizer yet); `re2-ui.js` `reLiability(r, p, prj)` (new-loan rows with security, borrower, quoted/APR/effective, from–to; old loans with their state; `debtByYear`, `owedAt`, peaks), `RE_LENS_MEASURES`, `RE_SETTLE_VERDICT`, texts. Tests `lenses.test.js` (6) and `settle.test.js` (5). **The page (P5, `realestate-v2.html`, built to `reviews/v2/ux.md`):** steps `Your project · Your money · Your loans · Your properties · How to pay · When · Your answer` (no When for land). Step 0 `KindPicker` (five keyboard-selectable cards; buildings: live in one unit / let out entirely; land: hold with a sale year / "Build later" = `landVilla` with the build start 24 months on; collapses to one line + change) over the six shared field blocks (`LandFields`, `BuildFields`, `ReadyFields`, `UnitsFields`, `LettingFields`, `TaxFields`) plus `HoldFields` (white-land fee, zakat, sale) and `MarketFields`; `costRows` per kind. Your loans: a "secured on" chip and the "Keep or settle?" column from `household.settleAdvice`. Your properties: `propertyTable` (name, value, bank lends up to % + may be mortgaged, mortgaged by (→ `securedOn`), rent today, plan keep / sell at move-in / sell in a month + costs, I live here + let after I move + yield; undo on remove; warnings; phone cards). Plan editor: one mortgage `Pick` per mortgageable property (room net of its loan), the "Only dearer loans" settle option with its effect line, no cash-out on land. **Your answer** in the decision-first order: `AnswerLine` (verbs per kind from `reKindWords`), `LensCards` (least liability with its measure picker, richest in X years with its year picker, most cash & borrowing power at move-in / the horizon; cards merge when lenses agree, "● Recommended"; a click sets the plan shown), `LiabilityCard` (`reLiability`: the loan table, the three figures, the stacked debt-by-year bars, the keep-or-settle rows ending with what the plan does to each loan), `InvestmentView` for let-entirely buildings (return, yields, debt cover), `WatchOut` (≤ 5, decision-changing only), then **Details** closed by default (waterfall, both measures, the step-by-step, compare plans, break-evens, stress, liquidity, loan worth, early payoff, ready villa, every line, all rows, year by year, sensitivity; one `PlanPicker`). Print = a one-page answer. Scenarios: Save / Save as… / open scenario under `re2_scenarios` / `re2_current` / `re2_current_name`; **"Import from the previous version"** reads `re_scenarios`, converts with `re2Import`, writes copies into `re2_scenarios` (" (previous version)" on a name clash, undo, rows marked until saved again) — the old copies stay. The old rental steps, the header mode switch, the preview-copy banner and the terms notice are gone (`reBootCopy`, `reTermsNotice`, `describeOption` deleted from `re2-ui.js`; new `reKindWords`, `rePeakSpan`, `reDebtCover`). Wording per the 19-term guide; `lang="ar"` spans; 16 px inputs on phones; charts `aria-hidden` with a hidden sentence. Tests: `page.test.js` (3); the lead's `reviews/v2/p5-check.js` (every kind reaches the answer on desktop and phone with no page errors, an imported old-shape scenario equals the frozen engine, the three cards switch the plan, the properties table with undo, the liability rows sum to the new debt, no phone overflow, print = 1 page). **Search, polish (P6):** `optimizeRE` searches none ∪ {the two mortgageable properties with the most room today (`reSearchProps`: value × ltv − the loan secured on it) × now / when the land is bought / at build start} (1 + 3k options → 48 / 192 / 336 mixes for 0 / 1 / 2+ properties; any other property is a plan-editor choice), the settle policies asNeeded / forMax / none plus `dearer` when `reDearerLoans` finds an old settleable personal loan (yours or your spouse's) more than `dearerMargin` above the cheapest mortgage rate searched (×4/3), `plBy` me / spouse / both with a spouse who earns (×3 on mixes with a personal-loan step); fewer runs than mixes with identical results — one run per plan signature (a ready kind or land: land ≡ build = the purchase; a build starting with the purchase) and the four policies collapse to the `forMax` run when it attempted no payoff (`plan._trace`) — results add `runs`, `policies`, `dearer`, `searchProps`; summaries add `eqId/eqName/eqWhen/payoffs`; names "mortgage on {name} (max) at build start" with the kind's words (`reMixWords`); `cleanPlan` keeps a mortgage step that lent nothing but paid loans off for its room, so every mix round-trips through `computeRE`; `start.lenses[k].mix` carries `cleanPlan` (slice → merge too); `opts.policies` / `opts.props`. `reStartMonth(inp)` / `reAtStart(inp, d, landWithBuild)`: for land and the ready kinds a start date is the purchase month, so `timingSweepRE` / `optimizeRE` move the purchase without `landWithBuild` (a construction only) — the page uses both and passes `landWithBuild` (its earlier `lwb` option key was never read). `payoffs[]` carry `why` ("planned" | "room"), `forKey/forLabel`, `dearer`, `rate` (the page's keep-or-settle rows say "to make room for the land mortgage"). `household.capTimeline` rows carry `props[] {id, name, ltvRoom, maxMortgage, secured, sold}` and `propRoom` (a row when a property is sold in a month you set); `household.propertyRoom` = today's. `reExpl` texts for every new input and lens. `rePlanSimulate` is ≈30% faster (plain loops, year-cached limits, one growth factor a month; bit-identical). The tool's pick card says which properties the search mortgaged and whether "only dearer loans" was tried; the "NEW VERSION" badge is gone. Tests: `optimizer.test.js` (6: counts, runs = mixes' results, cleanPlan round-trip and the written plan ranking first, ready kinds' start dates, payoff reasons, property rooms); parity's optimizer check compares drawn amounts (`policies` override) and asserts the default search ranks no lower.
